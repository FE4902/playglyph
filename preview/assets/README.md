# Introduction comparison assets

- The current main-page comparison uses `site/pixel-game.gif`, a six-frame loop assembled from a sprite sheet generated with the built-in image generation tool. The full prompt and method are saved in `output/imagegen/pixel-game-prompt.txt`; `output/imagegen/playglyph-pixel-demo.gif` includes the Playglyph pixel HUD. `site/pixel-game-still.png` is used when reduced motion is preferred.
- The earlier `site/game-2d.svg` scene, generated by `node scripts/draw-demo-scene.mjs`, is retained as an alternate static demo.
- `luanti-soothing32.jpg` is an unused asset from the earlier demo: unmodified screenshot from the [Luanti official gallery](https://www.luanti.org/en/#gallery), [original image](https://www.luanti.org/media/gallery/2.jpg). Features the [Soothing 32 texture pack by Zughy](https://content.luanti.org/packages/Zughy/soothing32/). The [Luanti website README](https://github.com/luanti-org/luanti-org.github.io#license) credits gallery screenshots to their respective authors separately from the website's content license.
- `lucide/*.svg`: unmodified icons from `lucide-static@0.468.0`, downloaded from `https://unpkg.com/lucide-static@0.468.0/icons/`. See `lucide/LICENSE` for the included license notice.
- Playglyph icons are rendered from this project's local `dist/lookup.js` in pixel style, using native 16×16 definitions from `pixel/`.
