문서

Playglyph를 프로젝트에 넣고 스타일, 재질, 옵션을 쓰는 방법을 정리했어요. 아이콘 목록은 갤러리에서 볼 수 있습니다.

시작하기

세 가지 방법이 있어요. 빌드 도구가 없다면 CDN 스크립트가 가장 빠릅니다.

1 CDN 스크립트 빌드 없음

스크립트 한 줄이면 window.playglyph가 생기고, data-pg가 붙은 요소가 SVG로 바뀝니다.

<script src="{CDN}/playglyph.js"></script>

<i data-pg="heart" data-style="sticker"></i>

2 ZIP 다운로드

SVG 원본, ES 모듈, 전역 스크립트, React 컴포넌트, 스프라이트, llms.txt가 들어 있어요. 압축을 풀고 dist/playglyph.js를 불러오세요.

ZIP 받기 playglyph-0.1.0.zip 
<script src="./playglyph-0.1.0/dist/playglyph.js"></script>

3 npm npm 공개 예정

아직 npm에 올라가지 않았어요. 공개되면 아래 명령으로 설치합니다. 그 전에는 CDN 스크립트나 ZIP을 쓰세요.

npm install playglyph

이렇게 보여요

사용법

쓰는 환경을 고르세요. 코드는 오른쪽 위 버튼으로 복사합니다.

빌드 없이 스크립트 하나. 페이지가 로드되면 data-pg가 붙은 요소가 SVG로 바뀝니다.

<script src="{CDN}/playglyph.js"></script>

<i data-pg="settings"></i>
<i data-pg="coin" data-style="sticker" data-size="32"></i>
<i data-pg="shield" data-style="sticker" data-material="wood"></i>

나중에 추가한 요소(목록, 팝업, 다시 그린 HUD)도 자동으로 그려져요. 바로 다시 그리려면 playglyph.createIcons(), 자동 그리기를 끄려면 playglyph.stopAutoRender()를 부르세요. SVG 문자열이 필요하면 playglyph.icon()을 씁니다.

el.innerHTML = playglyph.icon('pause', { size: 32, color: '#fff' });

playglyph.createIcons();     // draw every <i data-pg> now
playglyph.stopAutoRender();  // stop watching the page for new elements

<i>에 aria-label을 붙이면 SVG로 옮겨지고, 없으면 장식으로 보고 aria-hidden="true"가 붙습니다. id, title, style, class도 함께 옮겨져요.

<button><i data-pg="pause" aria-label="Pause"></i></button>
<span><i data-pg="coin" data-style="sticker"></i> 1,250</span>

자바스크립트 없이 <img>로 쓸 수도 있어요. 단색 SVG는 currentColor로 칠해져 <img> 안에서는 검게 보이니, 재질 폴더에 있는 색이 들어간 파일을 쓰세요.

<img src="{CDN}/svg/sticker/coin.svg" width="32" height="32" alt="Coins">
<img src="{CDN}/svg/sticker/gold/shield.svg" width="32" height="32" alt="">
<img src="{CDN}/svg/filled/silver/settings.svg" width="24" height="24" alt="Settings">

<!-- {CDN}/svg/filled/<name>.svg
     {CDN}/svg/filled/<material>/<name>.svg
     {CDN}/svg/sticker/<name>.svg
     {CDN}/svg/sticker/<material>/<name>.svg -->

쓰는 아이콘만 번들에 들어갑니다. npm 공개 예정

npm install playglyph

import { Settings, toSvg } from 'playglyph';
import { Coin, renderSticker } from 'playglyph/sticker';
import { gold } from 'playglyph/materials';

el.innerHTML = toSvg(Settings, { size: 24, color: '#fff' });
el.innerHTML = renderSticker(Coin, { material: gold, size: 48 });

export 이름은 아이콘 이름이나 별칭을 PascalCase로 쓴 것이고, 끝에 Icon을 붙여도 됩니다(Settings, Gear, SettingsIcon). 전역 Map과 겹치지 않게 지도 아이콘은 MapIcon으로 가져오세요.

진입점내용
playglyph단색 아이콘 데이터, toSvg, toCanvas, toImage, toDataURL, 재질
playglyph/sticker스티커 아이콘 데이터, renderSticker, stickerToCanvas, stickerToImage, stickerToDataURL
playglyph/pixel도트 아이콘 데이터, renderPixel, drawPixel, pixelToCanvas, pixelToDataURL
playglyph/materials재질 10종(wood … holy)과 materials, resolveMaterial
playglyph/lookup이름으로 찾기: icon, getIcon, createIcons, resolveName, suggest. 모든 아이콘이 들어가서 트리셰이킹되지 않아요.
playglyph/reactReact 컴포넌트(단색)

아이콘 이름을 문자열로 받는 코드라면 playglyph/lookup을 씁니다. 여기의 createIcons()는 부를 때 한 번만 바꾸므로, 요소를 추가한 뒤에는 다시 불러 주세요.

import { icon, createIcons } from 'playglyph/lookup';

el.innerHTML = icon('gear', { style: 'sticker', material: 'wood', size: 32 });
createIcons(); // replaces <i data-pg> once

Lucide와 같은 방식의 컴포넌트입니다. npm 공개 예정

import { Settings, Heart, PauseIcon } from 'playglyph/react';

<Settings size={24} color="white" />

React 컴포넌트는 단색 스타일입니다. size(기본 24)와 color(기본 currentColor) 외에 className, aria-label 같은 SVG 속성을 그대로 넘길 수 있고, ref도 전달돼요.

<button aria-label="Pause">
  <PauseIcon size={32} color="#fff" aria-hidden="true" />
</button>

스티커나 도트가 필요하면 SVG 문자열을 돌려주는 icon()을 씁니다.

import { icon } from 'playglyph/lookup';

<span dangerouslySetInnerHTML={{ __html: icon('coin', { style: 'sticker', size: 32 }) }} />

로딩 때 한 번 이미지로 만들고, 매 프레임에는 drawImage만 부릅니다.

const coin = await playglyph.stickerToImage(
  playglyph.getIcon('coin', 'sticker'), { size: 64 });
ctx.drawImage(coin, x, y, 32, 32);

// Phaser
const pause = await playglyph.toCanvas(playglyph.getIcon('pause'), { size: 32, color: '#fff' });
this.textures.addCanvas('pause', pause);

toCanvas와 stickerToCanvas는 size에 devicePixelRatio를 곱한 크기로 그려서 고해상도 화면에서도 선명해요. pixelRatio 옵션으로 바꿀 수 있습니다. 캔버스 안에서는 currentColor가 없으므로 단색은 기본으로 흰색입니다.

// Pixi
const gem = await playglyph.stickerToCanvas(
  playglyph.getIcon('gem', 'sticker'), { size: 48, material: 'arcane' });
const sprite = new PIXI.Sprite(PIXI.Texture.from(gem));

도트 아이콘은 drawPixel로 캔버스에 바로 그립니다. 이미지 디코딩 없이 동기로 그려서 게임 루프 안에서 불러도 됩니다.

const heart = playglyph.getIcon('heart', 'pixel');
playglyph.drawPixel(ctx, heart, x, y, { scale: 2 }); // 16×16 cells → 32×32 px

const tex = playglyph.pixelToCanvas(heart, { scale: 3 }); // 48×48 canvas

ES 모듈에서는 toCanvas, toImage는 playglyph에서, stickerToImage, stickerToCanvas는 playglyph/sticker에서, drawPixel, pixelToCanvas는 playglyph/pixel에서 가져옵니다.

AI 코딩 도구에 이 한 줄을 알려 주세요. 아이콘 이름, 별칭, 사용법이 정리된 문서입니다.

{CDN}/llms.txt

llms.txt에는 아이콘 134종의 이름, 쓰임새, 별칭과 짧은 사용 예가 들어 있어요. 프롬프트에 이렇게 붙여도 됩니다.

옵션

HTML에서는 data-* 속성으로, 자바스크립트에서는 icon(name, options)의 옵션으로 같은 값을 넘깁니다.

<i data-pg="sword" data-style="sticker" data-material="steel" data-secondary="gold" data-size="48"></i>

playglyph.icon('sword', { style: 'sticker', material: 'steel', secondary: 'gold', size: 48 });
옵션 값 스타일 설명
styledata-style filled (기본) · sticker · pixel 전체 그리는 스타일. solid, color, retro 같은 다른 이름도 통해요.
sizedata-size 숫자, 기본 24 전체 가로·세로 크기(px). 도트는 16의 배수에서 또렷해요.
colordata-color CSS 색, 기본 currentColor 단색 · 도트 mono 단색 아이콘의 색. 스티커에는 쓰이지 않아요.
materialdata-material wood … holy 전체 스티커와 도트는 재질로 다시 칠하고, 단색은 재질의 대표색 하나로 칠합니다. 단색에서는 color보다 우선해요.
secondarydata-secondary 재질 이름 스티커 · 도트 손잡이, 장식처럼 보조 부분의 재질.
statedata-state disabled · locked 스티커 · 도트 disabled는 회색, locked는 어두운 실루엣. 잠긴 스테이지나 비활성 버튼에 써요.
borderdata-border CSS 색 스티커 외곽선 바깥에 테두리를 둘러, 어두운 HUD에서 아이콘이 또렷하게 떠 보여요.
shadingdata-shading gloss (기본) · full · cel · flat · mono 도트 명암 단계. mono는 color 한 색(기본 흰색)으로 그려요.
scaledata-scale 숫자, 기본 2 도트 도트 한 칸의 px. size를 주면 size가 우선해요.
classclass 문자열 전체 기본으로 붙는 pg pg-<이름> 클래스에 더해집니다.

예시

예시의 style은 생략했어요. 스티커는 data-style="sticker", 도트는 data-style="pixel"을 함께 씁니다.

스타일

같은 이름으로 세 가지 스타일을 그릴 수 있어요.

단색 filled

기본 스타일. 24×24 단색 아이콘으로, currentColor로 칠해져 글자색을 따라갑니다. Font Awesome의 solid와 같은 역할이에요.

스티커 sticker

두꺼운 외곽선, 그림자, 하이라이트가 있는 24×24 컬러 아이콘. 134종 모두 있고, 재질로 다시 칠할 수 있어요.

도트 pixel 베타

16×16 도트 아이콘. 16·32·48px처럼 16의 배수에서 또렷해요. 아직 일부 아이콘에만 있습니다.

재질

재질 하나로 세트 전체를 다시 칠합니다. 10가지가 있고, lava, poison, arcane, holy는 은은하게 빛나요.

색 띠는 각 재질의 다섯 단계(외곽선, 그림자, 본면, 밝은 면, 하이라이트)입니다.

<i data-pg="shield" data-style="sticker" data-material="gold"></i>
<i data-pg="sword" data-style="sticker" data-material="steel" data-secondary="gold"></i>
import { Shield, renderSticker } from 'playglyph/sticker';
import { gold } from 'playglyph/materials';

el.innerHTML = renderSticker(Shield, { material: gold, size: 48 }); // or material: 'gold'
  • 게임 UI 전체에 재질 하나를 정하면 통일감이 생겨요. 판타지는 wood, SF는 steel이나 silver, 보상 화면은 gold처럼요.
  • 하트와 코인은 재질 없이 두세요. 고유의 빨강과 금색 덕분에 플레이어가 색으로 바로 찾습니다.
  • 단색 아이콘에 재질을 주면 그 재질의 대표색 하나로 칠합니다. 없는 재질 이름은 steel로 그리고 콘솔에 경고를 남겨요.
  • 빛나는 재질을 쓴 도트 아이콘은 빛이 번질 자리로 사방에 2칸씩 여백을 둡니다.

이름과 별칭

아이콘 이름은 Lucide를 따릅니다(settings, volume-2, pause). 켬과 끔은 music / music-off처럼 -off로 짝을 이뤄요.

Lucide, Font Awesome, Material 이름 814개가 별칭으로 통합니다. 대소문자와 구분자(-, _, 공백)는 가리지 않고, fa-, mdi-, lucide- 같은 접두사와 -icon, _outlined, -solid 같은 접미사도 떼고 찾아요.

이름 확인하기

resolveName은 어떤 철자든 정식 이름으로 바꾸고, 없으면 null을 돌려줍니다. suggest는 비슷한 이름을 최대 limit개(기본 3) 찾아요. getIcon은 그 스타일의 아이콘 데이터를 돌려주고, 이름이나 스타일이 없으면 대체 없이 null입니다.

playglyph.resolveName('Gear');        // 'settings'
playglyph.resolveName('play_arrow');  // 'play'
playglyph.resolveName('castle');      // null

playglyph.suggest('setings');         // ['settings']
playglyph.suggest('treasure');        // ['map', 'treasure-chest']

playglyph.getIcon('crown', 'sticker'); // sticker data
playglyph.getIcon('crown', 'pixel');   // null (no pixel art yet)

없는 이름

없는 이름은 "?" 아이콘으로 그리고, 콘솔에 비슷한 이름을 알려 줘요. 오타가 있어도 화면은 깨지지 않습니다.

<i data-pg="setting"></i>
// console: playglyph: no icon named "setting", showing a placeholder. Did you mean: settings?

모든 이름과 별칭은 아이콘 갤러리에서 검색할 수 있어요.
